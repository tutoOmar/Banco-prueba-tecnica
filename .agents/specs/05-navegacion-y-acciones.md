Logic Spec (Smart Component: ProductListComponent)El orquestador ahora debe manejar la navegación y la apertura de menús:  Navegación: Al recibir el onClick del botón *Agregar*, utiliza Router.navigate(['/products/new']).  Menú Contextual:Gestiona un signal activeMenuId = signal<string | null>(null) para saber qué menú de fila está desplegado.Cierra cualquier menú abierto al hacer clic fuera (Listener global).2. Componentes Dumb AdicionalesA. Action Button (Botón *Agregar*)Estilo Senior: Implementar como un componente con ViewEncapsulation.None para permitir variaciones de tamaño si es necesario, pero manteniendo los estilos base.  Input: label: string (ej. *Agregar*).  Diseño: Fondo amarillo (--color-primary), texto azul oscuro, fuente negrita y border-radius: 4px.  B. Action Menu (Los tres puntos ⋮)Visual: Botón minimalista con el icono de puntos verticales.  Dropdown: Un contenedor con position: absolute y z-index elevado que contiene las opciones *Editar* y *Eliminar*.  Outputs:onEdit: Emite el producto para navegar a /edit/:id.  onDelete: Emite el producto para abrir el modal de confirmación (F6).  3.
